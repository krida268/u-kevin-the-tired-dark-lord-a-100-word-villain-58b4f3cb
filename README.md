## What it does

`main.ts` writes a monologue of exactly 100 words to `/output/entry.txt`: a fantasy villain who is secretly just very tired. He never says he is tired — the tiredness lives in the pauses, the deflections, and the small surrenders. A lord who built an empire on four hours of sleep now hands it over for a cup of tea, and asks only that the invasion wait until Thursday.

## Run it

```sh
node main.ts /tmp/out
```

The program accepts an optional output path (a file, or a directory in which it writes `entry.txt`); with no argument it writes to `/output/entry.txt`.
